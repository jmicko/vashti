# Fixed public Verify3 IQ4 register controller

The internal selector is
`KUNO_LAB_TARGET_IQ4_DECODER=packed-registers-public`. Absence preserves the
original decoder and all existing controller scopes. The normative leaf is
[the original-F32 Verify3 IQ4 register lookup](kuno-native-verify3-iq4-registers.md).
This controller changes no installed inference, API, model catalog or Vashti
behavior.

## Initial admitted scope

Only the compiled original CPU13 single warm replay and code/prose200
speculative fixtures may select the candidate. They require the accepted
Intel target plus independent Intel full-Q8 MTP runtime, original frozen host
sources and GPU router, partition exit, direct fill, inline direct-device build,
Verify3-fused, chunk I/O, request reuse and fused MTP sweeps. Actual Intel
admission, adapter/device/runtime identity and complete owners retain their
existing proofs. Unknown, empty, duplicate and partial selections reject before
model allocation. No implicit hardware/profile fallback is added.

The initial selector rejects Nvidia MTP placement, target-only, Q2 draft,
English shortlist, broadcast Q8 head and DOWN stride. Those existing modes
remain available when this selector is absent. Shared Q8 head, ordinary or
integer/stride GU, plain/four-row/integer DOWN, grouped PLE/status,
chronological QSA and bounded ThreeGdn may compose under their unchanged
individual prerequisites. Tables, shared DOWN scales, shared GU factors,
two-row GU, staging, three-member math, preserved bank placement and
prepared/live reductions remain excluded.

## Actual execution and immutable selection

The executor starts with private `Iq4Decoder::Original` and zero candidate
calls. One explicit activation requires its actual healthy model admission,
144-bank DASLab target, full Verify3-fused policy, authenticated frozen source
identity and original target request-I/O configuration. Repeated activation
rejects; there is no inference-time toggle or public writable decoder field.
Fresh construction and completed close retain the original default.

Language first completes its original real prompt prefill and first target
output, including existing teacher-KV, full-row, greedy and causal checks.
It records Original/zero evidence before source attachment. Only the accepted
source attachment and router activation may enable the decoder, before timed
continuations. CPU13 cold inference stays Original/zero; after the consumed
original full warm-reset audit, source attachment and router activation enable
the candidate before the first warm count1 token. That token still passes the
original full-vector reference. No references or tolerances are changed.

The real `enqueue_matrix_batch` Verify3 branch creates the original bounded
`MatrixSpec` and selects the packed decoder only for raw dtypes 20/23.
Unsupported formats retain exactly their original spec and receive no
candidate credit. The immutable leaf policy participates in its public
pipeline key; count, offsets, source identity, tokens and private values remain
outside that key. Original scalar projection entrypoints are untouched.

Candidate call counts increment only after the actual selected IQ4
`matrix_verify3`/`matrix_verify3_finite` enqueue returns successfully. Checked
overflow rejects before that launch. The controller publishes these scalar
counts only after original whole-model acceptance. They cover actual selected
IQ4 tiles for counts 1..3, including partial tiles and repair packets, rather
than inferred requests or pipeline names. They exclude other dtypes, scalar
entrypoints, routed experts, PLE/embedding work and the independent MTP engine.
They do not measure shader instructions or establish hardware speed alone.

## Exact receipts and limits

Outer fields `target_iq4_decoder_mode` and `target_iq4_decoder_requested` record
the requested canonical mode and boolean. Actual per-pass/record
`target_iq4_decoder` is `original` or `packed-registers`, read from the executor.
`target_iq4_decoder_receipt` contains `selected`, `successful_dispatches` and
`verify3_dense_dispatches`. Selected actual mode must match the request and
have a positive candidate count no larger than the real existing dense count.
Original mode requires zero candidate calls, including cold inference.

Initial evidence uses `initial_prefill_target_iq4_decoder` and
`initial_prefill_target_iq4_decoder_receipt`. Real language prefill and CPU13
cold evidence are Original/zero. CPU13 warm evidence must be the actual
candidate with positive successful calls. No prompt, output, token, vector or
route history is persisted.

No MAIN, HOST, runtime/INFO, source page, binding, owner, barrier or dispatch is
added by this decoder. Existing caps, combined Intel admission, selected
GU/DOWN owner increments, full finite/tail/fault gates, all-family acceptance
and complete close remain unchanged. The source-only counter is not a new
GPU buffer. No runtime backlog/cadence or deadline change is part of this work.

## Acceptance boundary

Controller/executor source checks passed: 41 language-controller, 33 CPU13,
29 receipt/helper and 5 executor tests (108 total), plus strict direct-device
all-target Clippy with two build jobs, formatting and diff checks. Independent
packed-codebook/shader/pipeline proofs belong to the leaf; original operator
controls must remain alongside the candidate.
Physical decoder values, dense counts 1..3, unchanged CPU13 vectors/greedy/
real repair, full source/owner close and memory recovery are mandatory before
normal same-artifact compiler-idle timing. None is established by a requested
selector or successful compilation. Root owns those GPU and lifecycle gates.
