This default-off internal leaf extends only the existing alternate

not original-F32 equivalence, a connected four-row transaction or a speed
claim. Original count1..3 Rust/WGSL entries, arithmetic and kernel identities

## Geometry and workspace contract

`grouped_moe::Geometry::with_four_members()` creates a separate immutable
frozen+partition-exit tile8 policy. `four_members()` reports it and
`member_limit()` is3 for ordinary frozen sources,4 when selected, and the
existing member capacity for nonfrozen geometry. All owning limits remain
MAX8 tokens/MAX80 routes/MAX80 groups and the existing804-word MAP. The flag
rejects old tables, scales/factors, paired/four-row/three-member arithmetic,
secondary, live and non-DAS geometry; reverse composition is rejected too.

Workspace selection is defaultfalse and occurs only at a healthy completed
accepted public warm boundary, before Sources attachment or router activation.
`set_public_four_members_policy(executor,graph,arena,enabled)` requires the
real target_four_rows_reserved permission, original DAS144/full target owners,
GPU-router reservation, actual constructor-reserved four-member router
logical span and both existing integer scratch owners. It adds no allocation. The parent owns Source reconstruction/immutable flag parity,
actual MAX40 router groups, all-family transactions and completed counters.

## Separate exactcount4 entries

Child modules `frozen_gu_integer::four` and `frozen_down_integer::four` retain
the original prepare/launch/audit signatures and original binding order. GU
also retains `launch_group_stride4`. Every entry requires exactlycount4;
explicit host and uniform shader guards precede accesses. Pipeline keys remain
public stage/dtype/row bytes. Original quantizer, weight decoders, codebooks,
signed quartet dots, i32 accumulation order, F32 plane/factor round points,

and256 initialized reduction cells replace the original vec3/192cells.
All actual original route IDs, shard positions and original rank outputs are
retained. No CPU-private planes, weight conversion or new source data exists.

GU uses64 header words plus4*1440=5824 meaningful words. Its prepare grid is
1*4*1 with128 lanes, project80*groups*1 with64 lanes (or80*4*1 stride), and

prepare is1*40*1 with64 lanes, project320*groups*1 with64 lanes, and full

tail are deterministic, and audits retain sticky fault8 without clearing.

Original numerical tolerances, full CPU13 vectors, real target greedy and
