## Exact internal metadata and grammar

Each cohort WGSL INFO has48u32/192 logical bytes: the original16-word Params
shape followed by8 records of4 words. Header fields are prompt count, role
columns, role rows, row bytes, first original group, role(0/2), gate bytes/4,
up bytes/4, complete original per-expert raw bytes/4, cohort size, largest real
member count, fixed matrix family(0/8/16), original mixed-F16 input bit and3
zero spare words. A record is original group, real members, canonical padded
row prefix and actual raw slot(0–7) or8 for a wholly resident source. Unused
records are zero. Matrix INFO appends the unchanged actual six-array metadata
(12words), for240 logical bytes. New cohort ArrayArgs supply the actual
scalar-half count so CubeCL vectorization reports the complete real vec4
length; the original noncohort constructors/grammar remain unchanged. Original full-capacity INFO erasure applies.

The new grammar authenticates this distinct layout, genuine bindings/grids and
whole source/owner spans before enqueue. It does not pretend a grouped dispatch
is an original one-expert call. Every shader rereads its original map/header,
member/route bounds and exact source-role extents. Only genuine inactive8/16-row
padding is initialized. Sentinel8 faults if any actual role is HOST; mixed
GPU/HOST gate/up sources retain the original per-role addresses and leases.

Phase order is Gather, GU image, DOWN image, each present GU family, validating
activation, each present DOWN family. Original large groups can occur only
between completed cohorts. Missing, foreign, reordered or incomplete phases
fail. Tape/backend reservations and all full-owner lifetime/hazard guards remain.
Bounded cohort metadata is wiped on normal/error drop.

Original logical phases/math populations remain independent of physical work:
6 phases and2 matrix products per original group; actual grouped launches,
cohort batches and groups are reported separately. `expert_native_scratch_groups`
counts only groups using the original two-slot path. Its existing scratch-slot
counter describes the2 views still carved per layer; an additional counter
records legacy slots actually used. Cohort counters report image slots used,
8-slot/75MiB capacity and20MiB X/5MiB H extents per reused cohort layout. Their
summed profile values are not additional GPU allocation or resident bytes.
