# v0.13.0-beta.4

This beta updates the Vashti server and Android app only. Kuno and its optional
Intel runtime are not rebuilt or replaced. Stable remains on v0.12.0.

## Assistant

* Added a conversational Assistant workspace with persistent conversations,
  background tasks, schedules, progress, questions, and inline results.
* Added explicit tool permissions and exact-action approvals, including
  approval-bound task creation and editing. Background workers cannot delegate
  recursively or access device-only private storage.
* Added resumable approvals, bounded execution, recoverable interruptions, and
  encrypted local drafts. Server restarts do not silently replay uncertain
  side effects.
* Added optional isolated, rootless Podman workspaces and downloadable task
  files. This requires a separately prepared server environment; it is not
  unrestricted access to the host or a full virtual machine.

## Models

* Added versioned inference defaults to custom models, including device-only
  models. Temperature and other controls can now be saved with the model.
* Conversation overrides take precedence without modifying the saved model
  version. Copies and historical versions preserve their settings.
* Moved custom-model creation and editing into a dedicated view with Back,
  Save, and unsaved-change protection instead of showing other models below it.
* Showed defaults reported by the base model as placeholders. Blank fields
  continue to inherit; unavailable runtime defaults are not invented.
* Fixed reopening encrypted device-only custom models after asynchronous
  decryption outlasted an IndexedDB transaction.

## Images And Video

* Added a separate Video workspace with capability-based host discovery,
  first-frame composition, progress, playback, downloads, retry versions,
  and saved or encrypted device-only flows.
* Video appears only on compatible, ready Kuno hosts. This release does not
  add video support to an older Kuno installation or install inference models.
* Restored thumb-accessible image and video inference controls in the lower
  composer. Settings scroll while the collapse and Send/Stop controls remain
  reachable; Enter in numeric fields no longer submits accidentally.
* Refined gallery loading, image viewing, comparison, zoom, and navigation,
  including stable layout while images load and improved private history.

## Interface

* Reduced visual clutter and added grayscale appearance choices while retaining
  the green theme.
* Restored horizontal settings navigation on mobile and refined sidebar,
  notes editing/history, model eligibility, and touch targets.

## Upgrade And Beta Limits

Back up the Vashti data directory before updating the server. New features add
forward database migrations; replacing the binary with an older version is not
a database rollback. Update both the server and Android app to test the new
server-backed features.

Assistant work is server-stored and continues only while the Vashti server is
running. Podman and any intended inference model must be prepared separately.
Existing compatible inference hosts remain usable without a Kuno version bump;
video requires the separately installed compatible backend capability.

Automated and browser checks are not a substitute for physical Android testing.
Installation, native playback/export, long-running use, and hardware-specific
inference should still be checked before stable promotion.
