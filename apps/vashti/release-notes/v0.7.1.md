# v0.7.1

This patch release makes chat sending resilient to temporary outages and server restarts. Failed messages remain visible and recoverable, interrupted generations no longer stay stuck forever, and physical keyboards keep desktop-style shortcuts even in narrow windows.

* Preserved unacknowledged outgoing messages locally instead of losing them when a request fails.
* Added inline retry and discard controls for messages that were not acknowledged by the server.
* Reconciled retries with server messages to avoid duplicates when the original request succeeded before the connection failed.
* Marked generations interrupted by a server restart as stopped during startup recovery.
* Restored first-message text and attachments when starting a chat fails.
* Distinguished mobile input behavior from narrow desktop windows and connected physical keyboards.
* Added `Ctrl+Enter` and `Command+Enter` send shortcuts while keeping `Shift+Enter` for new lines.
* Refined mobile viewport and keyboard handling around the chat composer.
