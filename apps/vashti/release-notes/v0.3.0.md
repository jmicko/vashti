# v0.3.0

This feature release adds the first profile and theme controls, including a light color scheme and a settings layout pass that keeps growing admin surfaces easier to scan. It also refines the chat layout and local development flow while preserving the recent model-picker and chat stability work.

* Added profile settings for display name, email, and color scheme.
* Added a light theme and remembered the last selected theme locally across sessions.
* Consolidated frontend colors behind theme variables so future color schemes can reuse the same UI surfaces.
* Added a reusable settings page layout with constrained headers, save banners, and content widths.
* Refined settings panels so create-user and add-backend forms stay out of the main flow until requested.
* Compacted desktop user cards so more accounts fit on screen without losing tag and admin controls.
* Refined chat message sizing so assistant output follows the composer width and user messages stay compact.
* Removed redundant user labels from user message bubbles.
* Let the top-right settings menu close when clicked away from or dismissed with Escape.
* Fixed Vite development routing so mutating requests proxy through Vashti without origin warnings.
