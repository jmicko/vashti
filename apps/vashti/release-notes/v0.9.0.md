# v0.9.0

This release makes branching conversations faster to explore and easier to compare. It adds a visual message tree, immediate revision switching, touch-first version navigation, and the ability to continue an existing assistant response.

* Added an interactive message tree with pan, zoom, focused-message inspection, and direct branch selection.
* Kept generations running while navigating other branches, with controls for returning to active and completed generations.
* Made switching between message revisions immediate by using the locally cached conversation tree.
* Added a swipeable message-version carousel on touch devices while retaining numbered arrow controls.
* Preserved full Markdown, thinking sections, tool activity, and message sizing while previewing adjacent revisions.
* Added the ability to continue an existing assistant response without replacing its current text.
* Corrected generation prompts so regeneration and branching follow the selected message ancestry.
* Preserved existing child paths when editing or switching message revisions.
* Added versioned presentation modes for custom models with scoped emphasized-text styling.
* Updated a transitive async dependency to remove a newly disclosed memory-safety issue.
