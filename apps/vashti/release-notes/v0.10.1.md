# v0.10.1

This prerelease provides the first live end-to-end validation target for Vashti's managed server updater. It contains the same managed-update feature set as v0.10.0 with updated release metadata so an installed v0.10.0 server can discover, verify, install, and restart into v0.10.1.

* Added a live signed update target for testing the complete administrator-managed update flow.
* Kept the Linux server and Android client versions aligned.
