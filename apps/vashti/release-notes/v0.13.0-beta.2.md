# v0.13.0-beta.2

This beta rebuilds Images around persistent conversational flows and integrates
the tested Kuno image engines. Upgrade Vashti, Android, and Kuno together; the
older beta image connector is not compatible with the new streaming contract.

* Added an image model picker using connected inference hosts, with actionable
  readiness notices and no manual image API key setup.
* Replaced the separate generation form with a prompt composer, streamed image
  responses, regeneration with new seeds, editing, and an explorable image tree.
* Added image-flow history and automatic titles, separate from chat history.
* Improved mobile controls, reference-image handling, aspect ratios, and matching
  an original image's proportions.
* Each automatic prompt improvement starts from the original submitted prompt,
  not the previous improvement. Saved generations retain their exact settings.
* Flow settings persist without changing account defaults. Explicit Save and
  Reset cover model/host, inference settings, seed policy, batch size, and prompt
  help. A new flow can reuse the current settings without changing defaults.
* Fixed persisted branch selection when submitting from another branch, and
  returning to a generation after navigating elsewhere.
* Saved Fast attention settings now require an explicit switch to Standard on
  a host that does not support Fast; no silent fallback changes the recipe.
* Added the optional managed Intel SYCL worker for Qwen Image 2.1 generation and
  editing. Qwen Image 2512 retains its native path. Runtime installation and
  selection remain explicit; installing the ordinary Kuno package does not
  install or enable Intel support automatically.

## Optional Intel Runtime

Download [kuno-sycl-linux-x86_64.tar.gz](https://vashti.chat/releases/v0.13.0-beta.2/kuno-sycl-linux-x86_64.tar.gz)
and verify its SHA-256 before extracting into an otherwise empty directory:

```sh
printf '%s  %s\n' \
  d242d7628ccb6c6048e7bdb7edca04d1c2e7453404e68667e829aff61b5ddd2f \
  kuno-sycl-linux-x86_64.tar.gz | sha256sum -c -
mkdir kuno-sycl-runtime
tar -xzf kuno-sycl-linux-x86_64.tar.gz -C kuno-sycl-runtime
sudo kuno install-image-runtime \
  --directory "$(pwd)/kuno-sycl-runtime" \
  --manifest-sha256 bf31edfe7c9630b6b6b367c98831aa7d4e931a797fcf29d519b00d7843413a99
```

Installation does not enable SYCL. Configure the existing image settings with
`engine: "managed_sycl"`, `runtime: "qwen21-sycl-2026.1-v1"`, the model store and
collections, and the intended GPU PCI address, then apply them with
`sudo kuno configure-image --settings /absolute/image-settings.json`.
Both operations prompt before interrupting running inference.

## Beta Limits

The Intel path was tested on Arc Pro B70 with working Xe/Level Zero drivers and
GLIBC 2.39. Its CPU objects require AVX2, F16C, FMA, and BMI2; older systems and
other GPUs are unverified. Standard Kuno has no private oneAPI dependency, but
this CUDA-enabled build also requires `libcuda.so.1` and Vulkan/GNU runtime
libraries, including on an Intel-only machine. It is not a general CPU-only or
driver-free build. Existing Landlock/cgroup-v2 and zero-swap privacy requirements
remain in force. Standard attention only is advertised by the Intel worker.

Live Vashti browser acceptance covered generation, editing, regeneration,
cancellation, saved settings, and branch navigation against installed Kuno.
Physical Android acceptance, overnight stability, and ComfyUI performance parity
are not claimed. The release runtime adds redistribution notices without
changing the hardware-tested worker or library bytes.
