# v0.2.1

This release rolls up the unreleased v0.2.0 model-picker work with the follow-up fixes from testing. It adds message stats, thinking-effort controls, default/favorite models, and mobile/chat stability fixes so this can replace the earlier pre-release.

* Added message stats for completed responses when Ollama provides timing and token counts.
* Added a message stats panel with output tokens, context tokens, generation time, prompt eval time, and tokens per second.
* Added thinking-effort controls for supported models, including auto, off, low, medium, and high.
* Remembered the last thinking mode used in a chat thread and preserved selected thinking mode when starting a new chat.
* Added per-user default model selection in personal model settings.
* Added favorite models, with favorites grouped at the top of the model picker.
* Added a Favorites section in personal model settings so starred models can be reviewed quickly.
* Added a delayed undo flow when removing a model from Favorites.
* Added sticky backend headers in the model picker to make long model lists easier to scan.
* Shortened Hugging Face model labels in the UI while preserving full model names in tooltips.
* Removed jumpy success text from settings where the changed control already provides visual feedback.
* Added persistent storage for per-user model visibility, favorite, and default preferences.
* Fixed freshly generated message edits showing stale duplicate content until refresh.
* Fixed mobile keyboard layout cases that could create black space above the keyboard.
* Fixed message scroll anchoring so chat history jumps less when loading markdown, images, and keyboard layout changes.
