# v0.11.0

This feature release adds a personal Markdown Notes workspace and lets users bring exact, permission-controlled note context into conversations. Server notes sync across a user's Vashti clients, while encrypted device notes stay inside the private-local storage boundary.

* Added a responsive Markdown Notes workspace with autosave, preview, pinning, tags, search, trash, restore, and immutable version history.
* Added server-backed notes for standard chats and encrypted device-only notes for private-local chats.
* Added explicit note attachments and pinned conversation notes that preserve the exact note version used for each message.
* Added permission-scoped Notes tools for searching, reading, creating, updating, and trashing notes, with global, per-user, per-chat, per-note, and per-model controls.
* Added authenticated client-tool handling so private chats can use device notes without persisting note data on the Vashti server.
* Added optional Ollama embeddings and hybrid semantic plus keyword search, with keyword-only fallback when semantic indexing is unavailable.
* Added direct links from note-related model tool activity back to the referenced note.
* Coalesced human autosaves into meaningful edit-session checkpoints while preserving conflict detection and immutable referenced versions.
* Simplified sidebar navigation, kept topbar controls visible while scrolling, and refined message emphasis above the composer.
