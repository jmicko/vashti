# v0.11.1

This patch release makes Notes permissions easier to understand and fixes defaults that could leave Notes tools unavailable or make model-created notes unusable without extra setup. Existing notes and explicitly saved access choices remain unchanged.

* Moved personal Notes access and new-note defaults into a dedicated Personal → Notes settings page.
* Kept the Notes chat toggle visible and added actionable explanations when another setting prevents Notes from working.
* Made untouched accounts and newly created notes ready for permitted models to use while preserving existing explicit settings.
* Ensured model-created server and device notes remain accessible to the model that created them.
