# v0.10.0

This release adds administrator-managed updates for Vashti Linux servers. Admins can choose a stable or prerelease channel, see when a new version is available, and install it from the App settings page without returning to a terminal.

* Added background checks for stable and prerelease server updates.
* Added update availability notices and release notes to the admin App settings page.
* Added one-click server update installation with progress shown in the interface.
* Added signed release manifests and artifact verification before installation.
* Added guarded service restart, health checks, and automatic rollback when an update cannot start successfully.
* Preserved manual installation and recovery paths for administrators who prefer terminal-based updates.
* Expanded release infrastructure to retain multiple prereleases for end-to-end updater testing.
