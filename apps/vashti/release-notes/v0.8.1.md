# v0.8.1

This release rolls the native Android client into a corrected prerelease for end-to-end testing. Vashti servers now offer the Android build matching their own exact version instead of sending prerelease testers to the older stable release.

* Added a native Android client built with Tauri, including a first-run server connection flow.
* Stored Android connection credentials in the platform keyring and kept authenticated requests scoped to the selected Vashti server.
* Added stable server identities so the Android client can recognize connection changes safely.
* Added native-aware API transport, streaming generation support, attachment handling, and private storage integration.
* Added Android safe-area handling and responsive startup behavior for modern phone displays.
* Added signed Android APK packaging and multi-artifact publishing through Vashti Hub.
* Updated Hub release pages and APIs to support Linux and Android downloads from one release.
* Fixed custom-model profile and background images selected through mobile file pickers becoming unreadable before save.
* Preserved JPEG, PNG, and GIF uploads while converting other browser-readable image formats to lossless PNG.
* Fixed the Android download in Profile settings so it matches the connected Vashti server version, including prereleases.
