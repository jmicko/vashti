# v0.1.8

This release sharpens the settings experience around permission tags and continues the frontend cleanup work. Tag editing should feel much closer to the rest of the app, especially on mobile, while the chat code is now easier to maintain behind the scenes.

* Refactored the frontend into focused modules so app shell, chat views, settings pages, model picker, attachments, markdown rendering, and shared helpers are separated from the root app bootstrap.
* Added shared generation-stream parsing and message-version navigation helpers to reduce duplicated hosted/private chat code.
* Reworked permission tag entry with an app-styled suggestion menu instead of the browser datalist.
* Made tag suggestions clickable across the full row and added keyboard navigation with arrow keys plus Enter.
* Improved mobile tag editing behavior so suggestions stay available while repositioning the screen after the keyboard opens.
* Prevented tag input from looking like a password/payment/autofill field on mobile browsers.
* Made tag chip delete/restore behavior consistent across default tags and manually added tags.
