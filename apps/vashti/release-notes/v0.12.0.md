# v0.12.0

This feature release adds personal memories and searchable conversation history, improves semantic retrieval, and makes model management and mobile chat controls easier to use.

* Added versioned, model-scoped memories with personal access controls, edit history, and reversible deletion.
* Added permission-controlled search of past conversations with keyword and semantic retrieval.
* Added a setup screen for settings a user has not yet chosen, including choices introduced by later updates.
* Improved semantic note retrieval performance and corrected index rebuilds.
* Added managed Ollama model downloads that accept either a model name or a copied `ollama pull` command.
* Added favorites for custom models and background image preloading with bounded in-memory caching.
* Added pull-to-refresh from the top bar, triggered only after crossing the threshold and releasing.
* Improved mobile message-version swiping and expanded message editing space.
* Added conversation-only base model overrides for custom models, with a searchable picker and inline help under Inference.
* Moved New Chat beside Notes above the chat list and kept its label visible on narrow screens.
* Updated frontend dependencies to address reported security advisories.
