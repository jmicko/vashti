# v0.6.0

This feature release adds reusable context libraries for changing a conversation's project, scenario, mood, or other prompt material without duplicating custom models. It also includes a broad runtime hardening pass for authentication, local data, uploads, proxy-aware rate limits, and direct web fetching.

* Added reusable context blocks that work independently with regular and custom models.
* Added user-created categories with choose-one and choose-multiple selection rules.
* Added ordered per-conversation context selection directly in the model settings menu.
* Added owner-only server context libraries for standard chats.
* Added encrypted device context libraries for private-local chats without storing their metadata on the server.
* Versioned context block edits and pinned exact versions to chats and generated messages so old conversations remain stable.
* Preserved selected context after a source block is removed from the active library.
* Added inline category creation while creating or editing a context block.
* Added compact, collapsible category sections with clearer separation between categories and blocks.
* Enforced context selection, ownership, ordering, and compiled prompt size limits on the server.
* Strengthened account input validation and required longer passwords in release builds.
* Made login and registration rate limits use verified client addresses, including trusted reverse-proxy deployments.
* Reduced unnecessary session database writes while preserving active-session tracking.
* Hardened direct web fetches against private, reserved, tunneled, and DNS-rebinding targets.
* Added global request limits and stricter attachment validation based on file contents.
* Restricted local data directories and database files to the service account on supported systems.
