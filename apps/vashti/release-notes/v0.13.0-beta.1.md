# v0.13.0-beta.1

This is the first testing release of Kuno and Vashti Images. Stable installations remain on v0.12.0.

## Images

- Generate and edit Qwen Image 2.1 images from the Images workspace or chat tools. The older Qwen Image 2512 workflow remains available.
- See live low-resolution previews while generation runs, then the completed image.
- Use multiple reference images, original-image editing or iterative editing, retries, gallery stacks, and saved generation settings.
- Configure generation defaults and which settings chat models may change.
- Improve prompts with optional LLM assistance, guidance, and saved prompt history. Automatic improvement is opt-in.
- Import supported ComfyUI generation settings from PNG metadata.
- Kuno keeps image prompts, references, previews, and results transient. Vashti owns storage; private-chat image results stay in the device vault.

## Kuno

- Install a Linux inference gateway on the model host, preserving existing clients' Ollama address.
- Coordinate configured GPU workers and native image generation, with content-free diagnostics and recovery tools.
- Download curated model collections with pinned revisions and checksum verification.
- Install or upgrade from the release page using a single script. It asks before interrupting inference.

## Beta limitations

- Initial GPU and image-model configuration still uses the CLI. Automatic hardware setup, idle profiling, and the model collection picker are unfinished.
- The tested image configuration uses the RTX 3060. Intel image performance remains experimental; ComfyUI-equivalent performance is not promised.
- Inference remains serialized, even when models stay resident on separate GPUs.
- Gallery removal hides entries; storage reclamation and deletion controls are unfinished. Large histories currently have bounded result/stack lookup.
- Incrementing seeds across separate chat tool calls and tool replay handling need further work.
- Android image export and the full edit/branch/endless-generation regression matrix still need device testing. This beta is not promoted to stable.
