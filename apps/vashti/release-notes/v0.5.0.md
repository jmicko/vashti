# v0.5.0

This feature release gives models a stronger identity and makes conversation behavior much more configurable. Custom models now live alongside regular models, chats can override system prompts and inference settings, and both regular and custom models can carry profile images and responsive chat backgrounds.

* Folded personas into the Models settings page as Custom Models.
* Added a model settings menu with custom-model version selection and per-conversation controls.
* Added per-chat system prompt overrides for hosted and private chats, including changes made before the first message.
* Added editable inference controls for context length, output length, sampling, penalties, GPU layers, CPU threads, and seed.
* Added inline explanations and individual reset controls for inference settings.
* Added a shortcut that creates a new custom model from the current conversation settings.
* Improved the mobile composer with a compact auto-growing input and an optional full-screen writing view.
* Kept manually expanded thinking sections open after generation finishes.
* Added uploaded, cropped profile images for hosted and device-only custom models.
* Added server-default and per-user profile images for regular models.
* Added configurable chat backgrounds for regular and custom models, including server defaults and personal overrides.
* Added separate portrait and landscape background layouts with fill, fit, stretch, and tile modes.
* Added independent controls for image dimming, message backing opacity, placement, and tile size.
* Preserved original uploaded image files so future crops and presentation changes do not accumulate compression artifacts.
* Kept device-only custom-model images and backgrounds in local browser storage.
