# v0.1.7

This release combines the model-permission/settings work from the skipped 0.1.6 pre-release with the latest tool-use and private-persona fixes. Admins get tag-based model controls, users can keep their model picker cleaner, and tool-heavy/private-persona chats should behave more reliably.

* Added tag-based permissions for users, models, and tools.
* Added implicit `everyone`, `admin`, and per-user tags displayed as `@username`.
* Added personal model visibility preferences so users can hide accessible models from their own picker.
* Moved global model controls into the Backends settings tab, with expandable backend rows.
* Added global default model tags for newly discovered models, with an option to apply defaults to existing models.
* Made backend configuration visible to admins only.
* Required persona creation and edits to use an underlying model the user can access.
* Improved the Users admin page by separating the signed-in admin account from the manageable user lists.
* Compactly redesigned permission tag editors for model and tool settings.
* Removed Vashti's hard-coded tool-call round limit.
* Preserved ordered thinking, tool-use cards, and visible assistant output during streaming.
* Added stored ordering markers so newly generated hosted and private messages can preserve interleaved thinking/output order after reload.
* Fixed private-chat version navigation so private persona responses keep the persona selected instead of switching to the underlying base model.
* Matched private chat model-picker behavior to hosted chats when the active visible assistant response changes.
