# v0.13.0-beta.5

This prerelease updates Vashti Linux, Android, and Kuno together.

## Images and video

- Kuno's Rust engine serves images and video from the same executable on
  supported GPUs. The old separately installed Intel/SYCL runtime is no longer
  needed. Kuno's upgrade removes it and its obsolete configuration fields.
- Qwen Image 2512 can use the new INT8 collection and Fast attention. The image
  settings offer Fast when the selected host and workflow advertise it.
- The Video workspace supports text-only, start and end keyframes, and up to
  four ordered reference images. Compatible hosts offer Standard clips up to
  10.13 seconds and High-resolution clips up to 5.17 seconds. Vashti sends the
  whole keyframe and explains how to recover from host memory limits.

## Conversations and documents

- Archive and restore chats without losing their messages or branches.
- Import a ChatGPT ZIP into server history or the encrypted device vault.
  Compatible imports preserve branches and attachments; supported Pages can
  open as editable Canvas documents.
- Use a chat-linked Canvas for writing or code, with version history and
  comments. New PDF attachments can use embedded text or local OCR.
- Automatic personalization can learn from eligible chats and imports. Rebuilds
  replay history in order, show progress, and can be canceled without replacing
  the current profile. Completion appears in Assistant.

## Upgrading

Back up Vashti data and the Kuno configuration before upgrading. Use matching
Vashti server and Android builds for testing. Upgrade Kuno through its installer
so it can migrate the old runtime configuration and files. Existing model files
are not included in the download and are not replaced by this upgrade. No
separate worker download or Intel runtime installation is required. Speech
support is not included in this beta.
