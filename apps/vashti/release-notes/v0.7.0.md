# v0.7.0

This feature release makes Vashti installable as a progressive web app and substantially improves repeat startup performance. Cached application assets and user-scoped data now appear immediately while Vashti safely refreshes them in the background.

* Added installable PWA support with platform-appropriate icons and Profile settings for installation.
* Added background update checks with an explicit prompt before activating a new app version.
* Added an offline-capable application shell while keeping authenticated API data out of the service-worker cache.
* Added encrypted, user-scoped caches for model-picker data and standard chat summaries.
* Loaded cached models and conversations immediately, then reconciled them with fresh server data.
* Reduced private-chat startup work by reading stored summary metadata instead of decrypting full conversations.
* Split large frontend views into on-demand bundles and deferred syntax-highlighting code until needed.
* Added Brotli and gzip delivery for compressible responses plus long-lived caching for revisioned assets.
* Kept HTML, manifests, service workers, and session responses revalidated or uncached so updates and account changes remain safe.
* Combined private-storage key delivery with the authenticated session response to remove an extra startup request without persisting the key in the general app cache.
* Refreshed Rust and frontend dependencies and added lightweight startup performance measurements for future tuning.
