# v0.1.5

This release expands Vashti's first tool-use pass into a more practical system for remote testing. It adds admin-configurable search/fetch tools, per-chat tool controls, and fixes the early provider wiring so each enabled tool is exposed and executed as its own Vashti tool.

* Added admin-configurable tool settings for Ollama and Brave web search/fetch.
* Added editable tool prompts with reset-to-default controls and current-date guidance.
* Added guarded direct page fetching for public HTTP/HTTPS pages.
* Improved the Tools settings UI with switches, changed-state indicators, and sticky save/revert controls.
* Added per-chat tool controls in the message composer, including global tool-use enablement and per-tool toggles.
* Added inline tool-use cards so real tool calls are visible in assistant responses.
* Fixed tool availability so Brave search, Ollama search, Ollama fetch, and direct page fetch appear separately when enabled.
* Fixed disabled chat tools so unavailable providers are hidden from the model instead of returning provider errors.
* Stored chat tool preferences by tool ID so future tools can be added without another chat schema shape change.
