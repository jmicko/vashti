# v0.1.6

This release focuses on model access control and the settings experience. Admins now have tag-based model permissions and global backend/model controls, while every user can keep their own model picker clean by hiding models they do not want to use.

* Added tag-based permissions for users, models, and tools.
* Added implicit `everyone`, `admin`, and per-user tags displayed as `@username`.
* Added personal model visibility preferences so users can hide accessible models from their own picker.
* Moved global model controls into the Backends settings tab, with expandable backend rows.
* Added global default model tags for newly discovered models, with an option to apply defaults to existing models.
* Made backend configuration visible to admins only.
* Required persona creation and edits to use an underlying model the user can access.
* Improved the Users admin page by separating the signed-in admin account from the manageable user lists.
* Compactly redesigned permission tag editors for model and tool settings.
